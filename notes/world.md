# 世界観・舞台設定 (world.md) :id=world

## 作品タイトル
**『嘘つきパレットと剥落の聖女 ―異端修復師は神話の塗り潰しを暴く―』**
（略称：『剥落のイコン』）

---

## 1. 舞台概要

### 1-1. 舞台名：聖彩教国フィレンツァ・ノヴァ（城塞階層都市アルテミシア）
- **地理・景観**:
  巨大なカルデラ湖の中央に聳え立つ、白亜と黄金の階段状城塞都市。都市全体が「ひとつの巨大な祭壇画」として設計されており、上層から順に以下の三層構造を成している。
  1. **【<ruby>天蓋聖堂区<rt>アウレオーラ</rt></ruby>】**: 最上層。純金箔とラピスラズリのドームが輝く聖彩教会の総本山。大聖堂の天井には、世界の始まりと秩序を規定する神話壁画『創世の大フレスコ』が描かれている。
  2. **【<ruby>彩光市民区<rt>キアロスクーロ</rt></ruby>】**: 中層。工房ギルド、画材商、貴族の館が並ぶ美しい石畳の街並み。街灯や動力機関はすべて後述する「<ruby>聖画<rt>イコン</rt></ruby>」の輝きによって稼働している。
  3. **【剥落迷宮区（スフマート / <ruby>灰底街<rt>スフマート</rt></ruby>）】**: 最下層。上層の工房から流れ落ちる廃溶剤、鉛や水銀を含んだ有毒な顔料廃液、そして劣化した廃棄聖画が堆積するスラム街。常に淡い <ruby>化学霧<rt>ケミカル・フォグ</rt></ruby>が立ち込め、住民の多くは防毒布やマスクを携行している。主人公ルカの闇修復工房『atelier ペンティメント』はこの最下層の水路沿いに位置する。

### 1-2. 時代背景・テクノロジー（ルネサンス×スチームパンク×化学光学）
- 15〜16世紀イタリア・ルネサンス期の美術・建築様式をベースに、光学レンズ（赤外線・紫外線プリズム）、蒸気噴霧器、精密化学（有機溶剤・重金属精製）が独自発達した世界。
- この世界には「銃火器」や「内燃機関」の代わりに、物質と魂の記憶を定着させた絵画――**『<ruby>聖骸画<rt>イコン</rt></ruby>』**が存在し、インフラ（発熱・照明・浄水・結界）から軍事兵器に至るまで、あらゆる文明の基盤となっている。

### 1-3. 基本的な社会構造と支配体制
- **<ruby>聖彩教会<rt>カテドラル</rt></ruby>による歴史と奇跡の独占**:
  教会は「神が遺した原初の聖画」を管理・修復する唯一の機関であり、公式の国家資格を持つ**『<ruby>聖彩修復師<rt>オフィシャル・コンサベーター</rt></ruby>』**のみがイコンに触れることを許される。
- **「塗り潰し（オーバーペイント）」による支配**:
  実は教会の権威の根幹は、過去の都合の悪い歴史や虐殺、異端の真実を描いたオリジナルの聖画の上から、<ruby>鉛白<rt>クレムニッツ・ホワイト</rt></ruby>と金箔で「都合の良い神話」を上塗り（オーバーペイント）することで成り立っている。下層の絵を暴く行為は**『剥離異端罪』**として即座に処刑対象となる。

## 2. 特殊法則・能力体系：【聖骸彩術（イコノ・アルケミア）】

### 2-1. 聖骸画（イコン）の構造と『画装展開（カンヴァス・ドライヴ）』
<ruby>聖骸画<rt>イコン</rt></ruby>は単なる絵ではなく、以下の厳密な**古典絵画の5層構造**によって成立する魔導・科学構造体である。
1. **<ruby>支持体<rt>サポート</rt></ruby>**: 古樹の板（ポプラやオーク）、<ruby>麻布<rt>カンヴァス</rt></ruby>、あるいは**「生きた人間の肉体・骨格」**。
2. **基底層（ジェッソ / <ruby>石膏地<rt>ジェッソ</rt></ruby>）**: ボローニャ石膏と兎膠（うさぎにかわ）を何層も塗り重ねて鏡面研磨した「魂の定着床」。ここが砕けるとイコンは永久に消滅する。
3. **<ruby>下絵<rt>ペンティメント</rt></ruby>層（シノピア / アンダー・ドローイング）**: 画家が最初に刻んだ「真実の設計図・本来の願い」。
4. **<ruby>彩色層<rt>ピグメント・レイヤー</rt></ruby>**: 鉱物・重金属・聖遺物から精製した顔料と<ruby>展色剤<rt>バインダー</rt></ruby>（卵黄テンペラや乾性油）の層。ここに励起光を当てると、描かれた事象や守護獣（**彩獣／ピグメント・ビースト**）が現実空間に立体投影・具現化する。これを**『<ruby>画装展開<rt>カンヴァス・ドライヴ</rt></ruby>』**と呼ぶ。
5. **保護ワニス＆<ruby>後補層<rt>オーバーペイント</rt></ruby>**: 表面を覆う樹脂層、および後世の人間が「元の絵を隠すため」あるいは「能力を書き換えるため」に上から塗り重ねた改竄層。

### 2-2. 顔料の化学特性と毒性（バトルおよび謎解きのコアギミック）
使用される顔料は現実の古典化学に基づいた明確な性質・弱点・猛毒を持つ。
- **【<ruby>鉛白<rt>クレムニッツ・ホワイト</rt></ruby>（クレムニッツ・ホワイト / 2PbCO₃·Pb(OH)₂）】**:
  教会が真実を隠蔽する「オーバーペイント」に最も多用する白色顔料。極めて高い隠蔽力と物理防御結界を持つが、**硫化水素ガス（H₂S）に触れると黒色の硫化鉛（PbS）へ急激に黒変・脆化する**という化学的弱点を持つ。
- **【<ruby>辰砂<rt>バーミリオン</rt></ruby>（バーミリオン / 硫化水銀 HgS）】**:
  焔や攻撃性の奇跡を宿す鮮烈な赤色顔料。強い紫外線やハロゲン触媒に曝露すると結晶構造が崩壊し、**黒色のメタ<ruby>辰砂<rt>バーミリオン</rt></ruby>へと変色（黒変現象）しながら猛毒の水銀蒸気を噴出**する。
- **【<ruby>真群青<rt>ウルトラマリン</rt></ruby>（ウルトラマリン / ラピスラズリ）】**:
  黄金より高価な聖なる青。物理的・光学的な劣化には最強の耐性を持つが、**強酸に触れると瞬時に<ruby>脱色<rt>ウルトラマリン・シックネス</rt></ruby>し、硫化水素を放出して崩壊**する。
- **【<ruby>雌黄<rt>オーピメント</rt></ruby>（オーピメント / As₂S₃）＆<ruby>花緑青<rt>エメラルド・グリーン</rt></ruby>】**:
  黄金や楽園の緑を模倣するために使われるヒ素系顔料。美しい輝きを放つが、加熱や酸分解によって**致死性のアルシン（ヒ素ガス）**を発生させる罠として機能する。
- **【聖骸彩（マミー・ブラウン / 神血顔料）】**:
  古代の聖者や「人柱となった人間」の遺灰・血液・瀝青を練り上げた禁断の顔料。これを用いて生きた人間に描かれたイコンが**『生ける<ruby>聖画<rt>リビング・イコン</rt></ruby>』**である。

### 2-3. 修復師の戦闘・調査技術：『科学鑑定』と『剥離解体（ストリッピング）』
異端修復師である主人公ルカは、武力ではなく**「<ruby>保存科学<rt>コンサベーション・サイエンス</rt></ruby>」**を極限まで応用してイコンの改竄を暴き、敵の<ruby>画装展開<rt>カンヴァス・ドライヴ</rt></ruby>を無力化する。
- **<ruby>光学透視<rt>マルチスペクトル・ルーペ</rt></ruby>**:
  赤外線（IR）プリズムで表面の絵具を透過して<ruby>下絵<rt>ペンティメント</rt></ruby>の「ペンティメント（描き直しの痕跡）」を暴き、紫外線（UV）蛍光で後世のオーバーペイント箇所を不自然な発光として特定する。
- **<ruby>亀裂読解<rt>クラクリュール・リーディング</rt></ruby>**:
  絵具表面の微細なひび割れ網（クラクリュール）のパターンから、乾燥速度、描かれた年代、使用された<ruby>展色剤<rt>バインダー</rt></ruby>（卵か油か樹脂か）、さらには画家の筆圧や感情の乱れまでをプロファイリングする。
- **<ruby>選択的溶剤剥離<rt>ソルベント・クリーニング</rt></ruby>**:
  下のオリジナル層を1ミリも傷つけず、上のオーバーペイント層だけを溶かすため、テレビン油、アルコール、アセトン、アルカリ水溶液などをその場で調合し、パレットナイフで改竄層だけを削ぎ落とす神業。
- **剥離転写（ストラッポ / Stappo）**:
  フレスコ画や大聖画から表層の絵具層だけを丸ごと引き剥がす必殺技法。対象の表面に特殊な温膠（にかわ）と麻布を密着させ、一気に引き剥がすことで、敵が纏う「偽りの神話装甲」を物理的に引っぺがす。

### 2-4. 能力の制約・リスク・コスト
1. **オリジナル層破壊の不可逆リスク**:
   溶剤の調合比率や作用時間をわずかでも誤れば、オーバーペイントだけでなく下層の「本来の絵（記憶や魂）」まで溶解し、対象（特に生ける聖画であるヒロイン）は廃人化または死亡する。
2. **重金属・<ruby>有機溶剤中毒<rt>ペインターズ・コリック</rt></ruby>**:
   鉛・水銀・ヒ素の粉塵や揮発性溶剤を扱うため、修復師自身も常に神経毒のリスクに晒される。主人公ルカは過去の事故により右目と肺に慢性的な鉛・水銀被曝の後遺症を抱えており、長時間の高濃度溶剤使用は喀血や視覚混濁を招く。

## 3. 重要用語集

- **<ruby>聖骸画<rt>イコン</rt></ruby>（イコン / Icon）**: 特殊な顔料と魂の波長を定着させた絵画。光を与えることで描かれた奇跡や『彩獣』を現実世界に顕現させる。
- **オーバーペイント（上塗り改竄）**: 本来の絵画の上から別の絵具を重ねて構図や意味を書き換えること。聖彩教会はこれにより歴史と奇跡の所有権を捏造している。
- **ペンティメント（悔恨の透け線）**: 上塗りされた絵の下から、本来の<ruby>下絵<rt>ペンティメント</rt></ruby>や最初の筆致がうっすらと透けて見える現象。偽装を見破る最大の突破口。
- **クラクリュール（<ruby>経年亀裂<rt>クラクリュール</rt></ruby>網）**: 絵具層に生じる微細なひび割れ。天然の経年亀裂と人工的に焼成した贋作の亀裂は明確に形状が異なる。
- **ボーロ（箔下赤土）**: 金箔を貼る直前に<ruby>石膏地<rt>ジェッソ</rt></ruby>へ塗られる赤茶色の粘土層。金箔の輝きに血のような温かみを与える。
- **生ける<ruby>聖画<rt>リビング・イコン</rt></ruby>**: 人間の生体（皮膚と神経網）を支持体・<ruby>石膏地<rt>ジェッソ</rt></ruby>として直接描かれた禁忌のイコン。ヒロインのイリスはその最高傑作『第七の聖女画』。
- **<ruby>異端審問修復庁<rt>インクィジシオン・レストウロ</rt></ruby>**: 教会の秘密警察にして特務修復師部隊。不都合なイコンの「強制上塗り（ホワイトウォッシュ）」や「焼却（サヴォナローラ処置）」を実行する。
